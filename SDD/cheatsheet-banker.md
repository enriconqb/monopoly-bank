# Cheatsheet Banker — Monopoly Classic

Satu halaman. Detail lengkap: [aturan-banker-monopoly.md](aturan-banker-monopoly.md). House rule sewa/bangkrut: [aturan-bangkrut-sewa.md](aturan-bangkrut-sewa.md).

## Nominal

- Awal: **$1.500** | GO: **$200** | Income Tax: **$200** | Luxury Tax: **$100** | Penjara: **$50**
- Hipotek: **50%** harga | Tebus: hipotek **+ 10%** | Jual rumah ke bank: **50%** harga rumah

## Checklist tiap giliran

1. Pemain selesai gerak → cek petak.
2. **GO** jika lewat/mendarat GO.
3. Properti kosong → **Beli** atau lelang (isi harga).
4. Properti orang → **Sewa** (skip jika hipotek). Jika pembayar tidak mampu: hipotek wajib atau bangkrut — [aturan-bangkrut-sewa.md](aturan-bangkrut-sewa.md).
5. Pajak → **Bayar bank**.
6. Kartu → Bayar/Terima/Transfer sesuai teks.
7. Bangun hanya jika set lengkap + even-build.

## Sewa cepat

- Set warna lengkap, tanpa rumah, tidak hipotek: sewa kosong **× 2**.
- Stasiun: 1→$25, 2→$50, 3→$100, 4→$200.
- Utilitas: 1 buah **4× dadu**, 2 buah **10× dadu**.
